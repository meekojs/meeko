# Test a Meeko application

## Testing an installed application

In an external project, install Meeko and run its checks from **your application's** root:

```sh
pnpm add @meekojs/meeko
pnpm exec meeko check .
pnpm exec meeko build .
```

`check` prepares and checks the project; `build` verifies production output. Run your application's own tests with your chosen test runner. Monorepo commands are in [Contributing to Meeko](contributing.md#monorepo-tests).

### Test an interaction in the browser

Playwright can check the rendered page and hydration without a Meeko-specific test utility. From **your application's** root:

```sh
pnpm add -D @playwright/test
pnpm exec playwright install chromium
```

**New file: `playwright.config.ts`:**

```ts
import { defineConfig } from '@playwright/test'

export default defineConfig({
  use: { baseURL: 'http://localhost:4173' },
  webServer: {
    command: 'pnpm exec meeko dev .',
    url: 'http://localhost:4173',
    reuseExistingServer: !process.env.CI,
  },
})
```

**New file: `tests/home.spec.ts`**, for the starter generated by `meeko init-framework`:

```ts
import { expect, test } from '@playwright/test'

test('the counter responds after hydration', async ({ page }) => {
  await page.goto('/')
  const button = page.getByRole('button', { name: 'Count: 0' })
  await expect(button).toBeVisible()
  await button.click()
  await expect(page.getByRole('button', { name: 'Count: 1' })).toBeVisible()
})
```

Run `pnpm exec playwright test`. In CI, install dependencies and Chromium, then run `pnpm exec meeko check .`, `pnpm exec meeko build .` and `pnpm exec playwright test` from the application directory. If you replaced the starter counter during the tutorial, adapt the test to your page's interaction.
